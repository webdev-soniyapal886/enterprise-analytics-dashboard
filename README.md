## ✨ Features
* **Real-time Data Visualization:** Dynamic charting powered by Recharts with high-frequency updates.
* **Optimized Performance:** Server-Side Rendering (SSR) with Next.js 14 App Router to ensure zero UI lag.
* **Responsive UI/UX:** Tailored for seamless display across desktop, tablet, and mobile screens.
* **Persistent State:** Theme (Dark/Light mode) and user preference management using Zustand.
* **Type-Safe Architecture:** Built ground-up with TypeScript for reliability and developer productivity.

## 🛠️ Tech Stack
* **Framework:** Next.js 14, React 18
* **Language:** TypeScript
* **Styling:** Tailwind CSS, Radix UI
* **State & Data:** Zustand, TanStack Query
* **Charts:** Recharts
